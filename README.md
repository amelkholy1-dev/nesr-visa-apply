# نسر الخليج — نظام طلبات التأشيرات

نظام **منفصل** عن نظام الجوازات. بيسجّل بيانات الجواز والصورة الشخصية وصورة الجواز، وإضافة Chrome بتملا فورم **«طلب تأشيرة»** (`visa.mofa.gov.sa/SmartForm/TraditionalApp`) من البيانات دي.

## المكوّنات

| الفولدر | الوصف |
|---|---|
| `server/` | Express + MySQL (`mysql2`). الدخول، الأشخاص، ملفات الضبط، رفع الصور، فحص MRZ، تجهيز بيانات الفورم |
| `public/` | الواجهة (JS عادي من غير بناء، عربي RTL) |
| `extension/` | إضافة Chrome (MV3): `content-app.js` جسر مع النظام، `content-mofa.js` بيملا الفورم، `background.js` وسيط |
| `tools/make-deploy.js` | بيجهّز `deploy/visa-apply.zip` + `hostinger-env.txt` |
| `test/` | اختبارات: MRZ/الأسماء، الـ API على MySQL، الواجهة والإضافة في Chromium |
| `DEPLOY-AR.md` | دليل الرفع على Hostinger بالعربي |

## قرارات التصميم

- **اللي بتعمله الإضافة:** نوع التأشيرة والجنسية والممثلية، عدد الدخول والصلاحية والإقامة (القوايم المتأخرة بتستناها)، الأسماء (عربي/إنجليزي، 15 حرف للخانة)، الصورة الشخصية (رفع حقيقي للمنصة)، الجواز والتواريخ (`yyyy/mm/dd`)، الديانة والحالة والجنس، التصنيف المهني والمهنة (بالاسم)، المؤهل والعنوان والإيميل، جهة العمل، منفذ الدخول وتاريخه.
- **اللي بتسيبه للمستخدم عمداً:** رمز الصورة (الكابتشا)، الإقرارات (أقر/الخصوصية/التعهد)، زرار «حفظ». مفيش تخطّي لأي حماية.
- **مفيش كلمات سر للمنصة** بتتخزّن: الإضافة بتشتغل في متصفح المستخدم وهو داخل بحسابه.
- القيم المشتركة (جهة العمل، المؤهل، الديانة…) في **ملف ضبط**، والشخص بيغلبها بقيمته.
- الصورة الشخصية: المنصة بتقبل أقل من **1 ميجا**، فالواجهة بتصغّرها قبل الرفع والسيرفر بيرفض الأكبر.
- MRZ هو المرجع للاسم الإنجليزي ورقم الجواز والتواريخ والجنس، ومعاه فحص أرقام التحقق (لو الدقة مش عالية بيتعلّم «راجع»).
- التسجيل: `listen()` فوراً والقاعدة بتتحمّل بعدين (Hostinger بيقتل التطبيق لو ما سمعش في 3 ثواني).

## التشغيل محلياً

```bash
cp .env.example .env   # واظبط القاعدة وADMIN_PASSWORD
npm install
npm start              # http://localhost:3000
```

## الاختبارات

```bash
node test/mrz-names.test.js                                   # من غير قاعدة
TEST_DB_NAME=va1 TEST_DB_USER=u TEST_DB_PASSWORD=p node test/api.test.js
RUN_BROWSER=1 node test/ui-e2e.js && node test/ext-e2e.js      # محتاجين playwright + Chromium
```

## اللي لسه ما اتجرّبش على المنصة الحقيقية

الإضافة اتجرّبت على نسخة منظّفة من صفحة المنصة (بدون سكربتاتها) مع سكربت بيحاكي تحميل القوايم. لازم تتجرّب مرة على المنصة الحقيقية: رفع الصورة، تحميل قوايم المهن/منافذ الدخول، وقراءة رقم الطلب بعد «حفظ».
